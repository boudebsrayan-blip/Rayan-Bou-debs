# Pull-Up Tutorial: 3D Animated Guide

- **`pullup-tutorial.mp4`**: the finished video (1920×1080, 30 fps, 69 s). Send this to clients.
- **`index.html`**: the same animation as an interactive page (open it in a browser, with play/pause and a scrubber).
- **`render.js`**: re-renders the video after edits: `node render.js pullup-tutorial.mp4` (needs Playwright + ffmpeg).

Chapters: Intro → 1. Grip → 2. Dead hang → 3. Pull → 4. Lower → Full reps (tempo) →
Mistakes (swinging, half reps, shrugging) → Progressions (dead hangs, scapular pulls, negatives, bands) → Recap.
